FAQ

Common questions

Everything people usually ask before their first message.

Do I need my own API keys?

No. Aries routes every request through its own infrastructure — you just pick a model and chat. There are no keys to manage or bills from separate providers.

Can I switch models in the middle of a conversation?

Yes. The full conversation context carries over when you switch, so you can draft with a fast model and refine with a stronger one without restarting.

What file types can I upload?

Images (PNG, JPEG, WebP), PDFs, and plain text formats including code files and Markdown — up to 50 MB per file.

Does Aries remember anything between sessions?

Yes — preferences, active projects and goals persist across conversations. Memory is structured and editable, so you control what stays.

Is it free?

You can try the chat free. Heavy or specialized usage may require a plan — open the chat for current limits.

Which models have web search?

The Anthropic Claude and Google Gemini families support web search natively through Aries. Other models work with your uploaded files and the conversation context.
